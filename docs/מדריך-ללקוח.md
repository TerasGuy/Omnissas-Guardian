# מדריך ללקוח — ארכיון Omnissa ו־Omnissa Guardian

עותק מקומי לקריאה ולניטור באתרים מנותקים. **זה לא אתר מראה ציבורי.** התוכן שייך ל־Omnissa ומיועד לשימוש פנימי אצלכם.

## מה יש במערכת

| תוכנה | תפקיד | כתובת |
|---|---|---|
| **ארכיון Omnissa** | קריאה וחיפוש במסמכי KB ותיעוד | http://127.0.0.1:8765/ |
| **Omnissa Guardian** | ניטור לוגים והצעת מאמר מהארכיון | http://127.0.0.1:8766/ |

## איפה הקבצים

בתיקיית הפרויקט (למשל `omnissa-docs-archive`):

| נתיב | מה זה |
|---|---|
| `Open-Archive.bat` | פותח את הארכיון בדפדפן |
| `Open-Guardian.bat` | פותח את Guardian |
| `Open-Download.bat` | מתחיל / ממשיך הורדת תוכן |
| `.venv\` | Python מקומי (נדרש להרצה) |
| `data\archive.sqlite` | מסד המסמכים של ההורדה |
| `data\assets\` | תמונות וקבצים מצורפים |
| `data\library\inbox\` | שמים כאן SQLite חדש לעדכון אוטומטי |
| `dist\Omnissa-Archive\` | חבילת לקוח מוכנה להפצה (אחרי `package`) |

## איך פותחים את הארכיון

1. לחיצה כפולה על `Open-Archive.bat`  
   או בטרמינל:

```powershell
.\.venv\Scripts\python -m omnissa_archive serve --port 8765
```

2. בדפדפן: [http://127.0.0.1:8765/](http://127.0.0.1:8765/)

שם אפשר לחפש מילים, לסנן לפי מוצר/גרסה/תאריך, ולקרוא מאמרים. בטבלת הקטלוג מוצג גם **מספר KB** (מתוך כתובת המאמר ב־kb.omnissa.com); לדפי תיעוד אין מספר — מופיע מקף.

## איך פותחים את Guardian

1. לחיצה כפולה על `Open-Guardian.bat`  
   או:

```powershell
.\.venv\Scripts\python -m omnissa_archive guardian --port 8766
```

2. בדפדפן: [http://127.0.0.1:8766/](http://127.0.0.1:8766/)

מגדירים מיקומי לוגים (ברירות מחדל מ־KB 1027744, וגם נתיב מקומי או UNC), מרווח סריקה (ברירת מחדל 60 שניות), ורואים התראות עם קישור למאמר בארכיון.

## איך מורידים תוכן — ומה קורה אם עוצרים באמצע

לחיצה כפולה על `Open-Download.bat`, או:

```powershell
.\.venv\Scripts\python -m omnissa_archive fetch
```

- כל כתובת בתור מסומנת `pending` / `done` / `error`.
- מה שכבר `done` **לא יורד שוב**.
- אם סוגרים את החלון באמצע (או יש קריסה), העמוד שהיה באמצע חוזר לתור ובהרצה הבאה **ממשיכים מהיכן שנעצרתם**.
- אין צורך למחוק את המסד כדי להמשיך.

לראות גילוי מחדש של כתובות חדשות ואז הורדה:

```powershell
.\.venv\Scripts\python -m omnissa_archive refresh
```

## איך מעדכנים מסד ללקוח (חודשי)

אחת לחודש אפשר להעביר ללקוח מסד מעודכן באחת הדרכים:

1. **תיבה אוטומטית:** העתיקו את `archive.sqlite` החדש אל `data\library\inbox\`  
   הקורא טוען אותו לבד בלי ריסטארט.
2. **מסך הגדרות:** בארכיון ← הגדרות ← טעינת מסד (קובץ SQLite).
3. **חבילה:** הכינו חבילה עם  
   `.\.venv\Scripts\python -m omnissa_archive package --output dist`  
   ושלחו את התיקייה `dist\Omnissa-Archive\` (כולל `library\archive.sqlite` ו־`assets\`).

חשוב: שלחו גם את תיקיית `assets` יחד עם המסד, אחרת תמונות עלולות להיות חסרות.

## התקנה חד־פעמית (אם עוד אין `.venv`)

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e .
.\.venv\Scripts\python -m playwright install chromium
```

Chrome מותקן במחשב נדרש לרינדור מאמרי KB.
